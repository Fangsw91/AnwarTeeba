# جرد السوبرماركت

تطبيق أندرويد للجرد يعمل دون اتصال بالإنترنت، وتُحفظ بياناته على الجهاز نفسه.

- استيراد الأصناف من ملف جداول (xls / xlsx / csv).
- بحث فوري بالاسم أو الباركود، ومسح الباركود بالكاميرا.
- تعديل سعر الصنف وتحديد نسبة الضريبة (0 / 1 / 2 / 5 / 10 / 16%).
- تقارير الجرد قبل الضريبة وبعدها، وتقرير مستقل لكل فئة ضريبية.
- تصدير النتائج ودمج ملفات الجرد الواردة من أجهزة أخرى.
