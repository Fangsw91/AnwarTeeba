# جرد السوبرماركت — تطبيق أندرويد بدون إنترنت

كل تلفون بيخزّن بياناته على نفسه (IndexedDB)، وما بيحتاج إنترنت أبداً بعد التثبيت.
بتستورد قائمة الأصناف، بتعدّ بالباركود أو بالاسم، وبتصدّر النتائج لـ Excel. وبتقدر تدمج ملفات من تلفونات ثانية.

## 1) الحصول على ملف APK (بدون Android Studio)

الـ APK بيتبنى تلقائياً على GitHub (مجاني):

1. أنشئ مستودع جديد (Repository) على GitHub، ويفضّل Private.
2. من داخل هذا المجلد:
   ```
   git init
   git add .
   git commit -m "جرد السوبرماركت"
   git branch -M main
   git remote add origin https://github.com/<اسمك>/<المستودع>.git
   git push -u origin main
   ```
3. افتح تبويب **Actions** بالمستودع ← شغّلة **Build APK** (بتبدأ لحالها بعد الـ push، وبتاخد 5–10 دقائق).
4. لما تخلص، ادخل عليها ونزّل **jard-supermarket-apk** من قسم Artifacts، فك الضغط، وطلع لك `app-debug.apk`.

> إذا فشلت الشغلة، افتح سجلّ الخطوة الحمراء وانسخ الخطأ، وبصلّحه لك.

**بديل:** افتح مجلد `android` بـ Android Studio ← Build ← Build APK(s).

## 2) التثبيت على التلفونات

1. ابعث ملف `app-debug.apk` للتلفونات (واتساب، كيبل، Google Drive…).
2. افتحه وفعّل «السماح بالتثبيت من هذا المصدر» وكمّل.
3. أول مرة بتفتح الكاميرا بيطلب إذن: اضغط **سماح**.

## 3) طريقة الاستعمال

1. **الأصناف:** من تبويب «الأصناف» اختر ملف **.xls أو .xlsx أو .csv** مباشرة (مثل ملف أصناف برنامج المحاسبة).
   التطبيق بيتعرف على الأعمدة من عناوينها (**رقم المادة، اسم المادة، آخر سعر شراء**)، وإذا الملف فيه عمود «الكمية» أو «الوحدة» بيقرأه كمان.
   ابعث نفس الملف لكل التلفونات واستورده على كل واحد. للتجربة السريعة فيه زر «جرّب بأصناف تجريبية».
   - إذا الملف بدون كمية دفترية، التطبيق بيعدّ ويحسب **قيمة المعدود** (الكمية × آخر سعر شراء) بدون فروقات.
   - الأصناف اللي باركودها مكرر بالملف بتنضاف بدون باركود وبتلاقيها بالاسم.
2. **الإعدادات:** اكتب **اسم مختلف لكل تلفون** (مثلاً أحمد، سامر، المخزن).
3. **عدّ:** امسح الباركود بالكاميرا 📷 أو اكتب الاسم أو الرقم، واكتب الكمية.
   - **البحث الفوري:** كلما كتبت (مثل «حليب» أو «المراعي») بتطلع قائمة بكل الأصناف المطابقة (لحد 200) مع سعرها ونسبة ضريبتها. «المراعي» و«مراعي» نفس النتيجة.
   - **تعديل السعر والضريبة:** افتح الصنف واضغط ✎ **تعديل السعر والضريبة**، وحدّد النسبة: 0 / 1 / 2 / 5 / 10 / 16%. التعديل اليدوي ما بينمسح لما تعيد استيراد الملف.
   - وضع المسح السريع: كل مسح = +1 تلقائياً.
   - صنف مش موجود؟ بتضيفه وبيظهر بالتقرير كـ «صنف مضاف».
   - أي سطر بتقدر تلغيه بـ ✕.
4. **الضرائب:** ملفات الأصناف عادةً ما فيها ضريبة، فمن تبويب **الأصناف ← تحديد الضريبة للأصناف** اكتب كلمة (مثلاً «حليب») واختر النسبة وبتنطبق على كل الأصناف المطابقة دفعة وحدة. إذا ملفك فيه عمود «الضريبة» (16 أو 16% أو 0.16) بيقرأه تلقائياً.
   - **الإعدادات ← الأسعار بالملف:** اختر هل «آخر سعر شراء» **شامل الضريبة** أو **غير شامل** (الافتراضي غير شامل). التقارير بتحسب قبل وبعد الضريبة على هذا الأساس.
5. **النتائج:**
   - زر **بدون ضريبة / مع الضريبة** بيبدّل عرض القيم.
   - **تقرير فئات الضريبة:** لكل فئة (0/1/2/5/10/16 وغير محدد): قيمة المعدود قبل الضريبة، مبلغ الضريبة، والقيمة بعدها، مع المجموع. اضغط على أي فئة وبتشوف أصنافها.
   - تقدّم الجرد، والفروقات (إذا في كمية دفترية)، وفلتر بالفئة.
   - **تصدير الجرد** (كل صنف مع أعمدة الضريبة والقيم قبل/بعد) و **تصدير تقرير الضرائب**.

## 4) جمع نتائج كل التلفونات عند المدير

بما إنه ما في إنترنت، الدمج بيتم بالملفات:

1. على كل تلفون: **النتائج ← تصدير الجرد** وابعث الملف لتلفون المدير (واتساب مثلاً).
2. على تلفون المدير: **النتائج ← دمج ملفات من أجهزة ثانية**، اختر الملفات واضغط دمج.
3. كميات كل جهاز بتنجمع على كميات تلفون المدير.

ملاحظات مهمة:
- تعديلات السعر والضريبة بتبقى على التلفون اللي عدّلها؛ بيانات الأصناف الجديدة بتوصل المدير مع ملف التصدير، بس التعديلات على أصناف موجودة عند المدير لأ. الأفضل تحدّد الضرائب عند المدير قبل ما توزّع نفس الملف، أو تستورد الملف من جديد على كل تلفون.
- لو جهاز كمّل عدّ وصدّر ملف جديد، دمجه بيستبدل الدمج القديم من نفس الجهاز (ما بيتضاعف العدّ). التمييز بين الأجهزة بالاسم، فلازم الأسماء تكون مختلفة.
- التلفون ما بيدمج ملفه هو.
- صدّر نسخة احتياطية بشكل دوري: لو انحذف التطبيق أو انمسحت بياناته بتروح بيانات هذا التلفون.

## 5) للمطوّر

- `www/` التطبيق نفسه (HTML/JS بدون إطار عمل). `www/db.js` منطق البيانات، و`www/csv.js` قراءة/كتابة CSV.
- `npm test` يشغّل اختبارات منطق البيانات (تحتاج `npm install` أولاً).
- بعد أي تعديل على `www/`: `npm run sync` ثم ابنِ الـ APK.
- قراءة الباركود بمكتبة ZXing (محلية، بدون إنترنت). الملفات بتنحفظ وبتتشارك عبر قائمة المشاركة بأندرويد.
